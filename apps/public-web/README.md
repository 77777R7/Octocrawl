# W2L public preview page

Build the static frontend with `npm ci --prefix apps/public-web` and `npm run build --prefix apps/public-web`. The output is `apps/public-web/dist`; the public service must serve this output and `POST /api/preview` from the same origin.

The page sends only `{ "url": string }`. It treats the returned Markdown as untrusted text and renders a small safe subset without injecting page HTML. The visible total elapsed includes the browser request and rendering, while `totalMs` in the API payload is server-side time.

The build writes the page's markup (`src/page.ts`) into `index.html`, so the headline, form and sections are in the HTML before any script runs; `src/main.ts` only brings them to life. It also renders nine English Markdown pages from `content/` into `dist/docs/` (each also published as its source, `index.md`), `llms.txt` and `llms-full.txt` for LLM readers, a `404.html`, `robots.txt` and `sitemap.xml`. The privacy page (`content/privacy.md`) states what the hosted page records; keep it in step with `packages/public-preview/src/site.ts`. Open `/docs/` on the local preview service for the introduction, MCP setup, task guides, and limits. The static pages have unique titles and descriptions, canonical links, a shared link-preview card (`public/assets/og-card.jpg`, a 1200×630 capture of the hero), shared navigation, and copyable code examples. Absolute URLs in these files are written as `__W2L_ORIGIN__`, which the preview server replaces with the public origin when it serves them. The site has no client-side routes: any path without a file returns the 404 page with status 404.

The mountain Hero and octopus source are optimized WebP copies of Howard's supplied images in `Downloads`. `octopus-silhouette.webp` is a 192 px mask made from the octopus source (its ink blurred as for the animated veil, holes filled) so the static octopus tints only its own shape. `octopus-mark.svg` is an unapproved 32–48 px draft. The current navigation uses the supplied octopus image itself; do not treat the draft as approved branding until Howard reviews it.
