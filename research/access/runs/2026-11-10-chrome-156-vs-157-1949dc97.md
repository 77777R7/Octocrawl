# M3.1: did Chrome 157 lower the local challenge baseline? 2026-11-10

Label: `research`. Task list: [docs/enhanced-access-tasks.md](../../../docs/enhanced-access-tasks.md), M3.1. Follows [M1](2026-11-10-exit-vs-environment-1949dc97.md).

**The question.** Local `installed_chrome` verified 13 of the 16 challenge pages on 2026-11-09 (weekly rerun, Google Chrome 156.0.8078.81) and 7–9 on 2026-11-10 (M1's arm A, Google Chrome 157.0.8103.50, which Chrome's own update installed that morning). The grant and the exit were the same, but the day and the engine commit changed as well. This run puts a Chrome 156 back beside the 157 on the same day, with the same exit and engine.

## Design and decision rule (written before any run; not changed afterwards)

- **Arm C156:** Chrome for Testing 156.0.8078.80, mac-arm64, from Google's Chrome for Testing bucket (`chrome-for-testing-public/156.0.8078.80/mac-arm64/chrome-mac-arm64.zip`, 195,027,080 bytes, MD5 matching the bucket's `x-goog-hash`; 156.0.8078.81 is not published as Chrome for Testing). Downloaded on Howard's word, 2026-11-10.
- **Arm S157:** the installed Google Chrome 157.0.8103.50, as in M1's arm A.
- **Everything else the same:** one API process on this Mac at `1949dc97`, the installed_chrome grant, `access: "enhanced"`, the exit the API gives the rung (the shell's Clash proxy, `127.0.0.1:7890`), the rung's own flags. `research/access/exit-split/chrome.sh` launches the build named in its state file and changes nothing else.
- **Pages:** all 16 of `challenge16`. **Rounds:** 2 per arm, alternating C156, S157, C156, S157.
- **Focus pages:** the four that the weekly run of 2026-11-09 read and that M1's arm A missed every time: capterra (T047), crunchbase (T048), cars.com (T071), stackoverflow (T076). A page passes in an arm when both of its rounds are verified.
- **Rule:**
  1. C156 verifies at least 11 of 16 in both rounds, passes at least 3 of the 4 focus pages, and S157 stays at 9 or fewer in both rounds → **the Chrome build is implicated**: 157, or Chrome for Testing against branded Chrome. Separating those two needs Chrome for Testing 157 (another download, Howard's call).
  2. C156 also stays at 9 or fewer in both rounds and passes at most 1 focus page → **not the Chrome version**: the change is on the sites' side or elsewhere in this Mac's setup.
  3. Anything else → **no conclusion**, said as such.
- **Known differences left in:**
  - Chrome for Testing is not the branded Google Chrome: it has its own name and does not auto-update.
  - The engine reads the Chrome major once per executable path, so a launch's own report of the version may name 157 in both arms. The build actually launched is the one the wrapper logs.
