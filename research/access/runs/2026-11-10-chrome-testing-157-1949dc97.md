# M3.2: is it Chrome 157, or Chrome for Testing against branded Chrome? 2026-11-10

Label: `research`. Task list: [docs/enhanced-access-tasks.md](../../../docs/enhanced-access-tasks.md), M3.2. Follows [M3.1](2026-11-10-chrome-156-vs-157-1949dc97.md).

**The question.** In M3.1, crunchbase (T048) and stackoverflow (T076) were read in both rounds by Chrome for Testing 156 and refused in both rounds by the installed Google Chrome 157. Those two builds differ in version and in branding. This run adds Chrome for Testing 157, which differs from the first in version only and from the second in branding only.

## Design and decision rule (written before any run; not changed afterwards)

- **Arm C156:** Chrome for Testing 156.0.8078.80, the copy M3.1 used.
- **Arm C157:** Chrome for Testing 157.0.8103.50, mac-arm64, from Google's Chrome for Testing bucket (`chrome-for-testing-public/157.0.8103.50/mac-arm64/chrome-mac-arm64.zip`, 196,583,703 bytes, MD5 matching the bucket's `x-goog-hash`). The same version number as the installed Chrome. Downloaded on Howard's word, 2026-11-10.
- **Arm S157:** the installed Google Chrome 157.0.8103.50.
- **Everything else the same as M3.1:** one API process on this Mac at `1949dc97`, the installed_chrome grant, `access: "enhanced"`, the shell's Clash exit, the rung's own flags; `research/access/exit-split/chrome.sh` launches the build named in its state file.
- **Pages:** all 16 of `challenge16`. **Rounds:** 2 per arm, in the order C156, C157, S157, C156, C157, S157.
- **Warm-up:** before the first run, each Chrome for Testing copy is started once on `about:blank` and closed, because in M3.1 the first run of a new copy timed out on four pages. The warm-up reads no site.
- **Focus pages:** crunchbase (T048) and stackoverflow (T076). That gives four reads per arm (2 pages × 2 rounds).
- **Rule:**
  1. C156 verifies at least 3 of its 4 focus reads, and C157 and S157 each verify at most 1 → **the version**: Chrome 157 is refused where 156 is read, whatever the branding.
  2. C156 and C157 each verify at least 3 of 4, and S157 at most 1 → **the branding**: the installed Google Chrome is refused where Chrome for Testing is read. That points at this Mac's Chrome (its profile-independent state, its components, its update channel), not at 157.
  3. Anything else → **no conclusion**, said as such. That includes C156 no longer reading the two pages.
- **Known limits:** two rounds per arm; one Mac, one exit, one afternoon. A rule-1 or rule-2 result names where to look next, not a cause.
