The run and the check are a record of what W2L did on that day; nothing in the manifest was replaced or dropped, and the flagged rows (two Chinese-language and one Arabic page, the possibly truncated Equinix URL, one URL shared by two source ids, the SEC filing, the two third-party mirrors of the Google report) stay in every denominator below.

The script records the checkout at its start, `d0b36a8`; the manifest freeze `e96a8e9` was committed 13 s after the batch started and changes only the manifest file. The `urlsFileSha256` in the batch record equals the frozen hash.
- One batch (`/v1/batches`, formats `markdown`), task `a6569107-7212-494e-908f-d50b3d871ec8`, 72 URLs submitted, 72 completed, `budgetExceeded: null`, wall 43.7 s for the batch (sum of per-item wall 145 s; median item 1.5 s, p90 5.3 s, max 8.6 s). Every request went through the cloud session's `HTTPS_PROXY`; the trace records `proxy_used` on each.
- `python3 research/coos-pilot/check-observations.py --workbook .w2l/coos-pilot/dataset.xlsx --batch .w2l/coos-pilot/run-2026-09-30/batch-items.json` (the script extended in the same commit as this record to check the cited page against W2L's `<!-- page N -->` markers). ## What the 119 "not found" are

Each cluster was checked by reading the captured markdown next to the public page; counts are observations.

1. **90 — Digital Realty metro pages (10 URLs), floor area per building.** The value is in the capture but glued to the previous unit's superscript: the page marks up `<span>12,000 ft <sup>2</sup></span><span>1,100 m <sup>2</sup></span><span>N+1 Cooling</span>` and W2L's markdown renders the adjacent inline spans as `12,000 ft 21,100 m 2N+1 Cooling`. The superscript's `2` joins the next number, so `1,100` cannot be found on a digit boundary. This is a W2L markdown defect (`extract-tf/src/markdown.ts` treats `<sup>` as plain inline text), and it hides every square-metre figure on these pages; the browser lane gives the same text (Zurich, Osaka).
2. **14 — financing amounts written in words.** The pages carry `$7.9 billion`, `A$16 billion`, `S$2.25 billion`, `JP¥191.6 billion (US$1.24 billion)`, `US$2.325b`; the workbook stores the expanded number (`7900000000`) and `check-observations.py` matches only literal digit spellings. The captures are complete; the matcher does not scale words to numbers.
3. **8 — Applied Digital earnings release (SEC filing HTML).** The extractor chose the `table` strategy (`pageType: collection`, confidence 0.2) and the markdown is the non-GAAP reconciliation table only (6,881 chars); the capacity figures in the release's prose are not in the capture. This is the largest-table-only weakness already recorded against `scrape-formats.markdown` in the M1 re-audit, now on a seed-user source. (The two financing amounts on the same page are counted in cluster 2.)
4. **3 — AirTrunk framework, page 8 PUE band.** The page's text layer ends at `AirTrunk PUE band below:`; the band's figures are drawn, not text, so no text-layer reader can find them (an OCR case).
5. **2 — STT framework, page 16 chart labels.** The labels are in the text layer as `43.0% 44.0% 52.0%`; the matcher looks for `43` and `52` and does not accept a trailing `.0`. A matcher limit, not a capture gap (`44` was found elsewhere in the document by chance, hence the `other_page`).
6. **2 — single values not in the captured text.** The Vantage APAC page as captured lists seven campus totals and none is the workbook's figure; the Raxio Angola page as captured has no opening year. Whether the pages changed since the workbook was compiled is not known from this run.

Of the 119, then, 101 (clusters 1, 3 and 4) are on W2L's side or need OCR, 16 (clusters 2 and 5) are the check script's matcher, and 2 are unexplained.

## Follow-ups from this run

- W2L: render `<sup>`/`<sub>` so a superscript digit never joins the next number (cluster 1, 90 observations on 10 URLs).
- W2L: raise undici's header limit (`maxHeaderSize`) for the http lane, or escalate `HeadersOverflowError` to the browser lane (5 URLs).
- W2L: the table strategy on a press release drops the prose (cluster 3; known from M1).
- Check script: scale `billion`/`million`/`b` spellings and accept `43.0` for `43` (16 observations).
- Product decision (unchanged from [files-check-2026-09-30.md](files-check-2026-09-30.md)): a recorded robots override for files the publisher links publicly; the `aka.ms` case adds shortlink hosts whose robots.txt says nothing about the target.
