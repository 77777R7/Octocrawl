# H0 egress comparison: Cloud Run direct and the proxy gateway on the parity crawl sites (2026-10-19)

ROADMAP PH stage H0, second measurement: whether hosted Octocrawl reads the crawl sites of [research/parity/sites.md](../parity/sites.md) better through the operator's residential gateway than from Cloud Run's own address. One-off Cloud Run Job on the hosted service's image and resources; it did not go through the gate and touched no live traffic.

- **When:** 2026-10-19 06:29–06:37 UTC; execution `h0-egress-vkpcw`, completed, 1 task succeeded. The job was deleted afterwards.
- **Image:** `asia-southeast1-docker.pkg.dev/octopus-w2l-20260924-7r7/w2l-public-preview/hosted-api:714af563856738b8a4d150eb666df0de32b99f25`, the image of the live revision `octocrawl-api-lean-714af563` (`h25lean`). The script was written at repository commit `a881773a`.
- **Resources:** `--cpu=1 --memory=2Gi`, `asia-southeast1`.
- **Two arms, proxied and not:**
  - **direct:** the hosted engine as `createHostedApi` builds it (`hosted: true`, `hostedNetworkPolicy()`, no proxy). Exit seen by ipinfo.io: `34.34.254.49`, SG, AS396982 Google LLC.
  - **gateway:** the same engine options but `hosted: false`, because a hosted engine refuses egress proxies (ADR 0005), with `egressProxies` set to the operator's rotating US residential gateway (Webshare, `p.webshare.io:80`, a new household address per connection, the gateway of [arm C](../access/runs/2026-10-11-pa4-3arm-c-webshare-d65614d.md)) and a `standard` grant naming `egress_sessions`. All 74 gateway pages record egress `p.webshare.io:80`, exit country US (`access.egress.exit`, from `https://ipinfo.io/json` through the proxy).
- **Pages:** for each site, its start page and the first URLs `map` found from it (at most 15), the same list for both arms. One page at a time; for each URL both arms read it back to back, the arm that went first alternating. Default scrape options (`formats: ['markdown']`, `timeout: 100000`): HTTP first, the browser when the page needs it. robots.txt obeyed.
- **Sites:** the hosts of the crawl and batch cases (L02, L04, L11, A13–A15, A26–A35): books.toscrape.com, quotes.toscrape.com, www.scrapethissite.com/pages/, docs.python.org/3/, www.data.gov.uk search for energy, a Statistics Canada listing (`www150.statcan.gc.ca/n1/en/type/data`), and Wikipedia's Web crawler article. `map` gave fewer than 15 URLs on three: 6 on scrapethissite, 7 on data.gov.uk, and none beyond the start page on Wikipedia (the article's path has no subtree), so 74 URLs in all rather than 105.

- Every page in both arms answered HTTP 200. No page was `blocked` and none was `policy_denied` in either arm.
- The same two URLs failed in both arms, with the same reason and the same Markdown length: `quotes.toscrape.com/login` (a login form, `failed/empty_unverified`, 222 characters) and `docs.python.org/3/genindex.html` (`failed/empty_unverified`, 2,956 characters). These are the engine's judgement of the page, not the exit.
- Lanes: direct read 63 pages over HTTP and 11 in the browser, the gateway 68 and 6. The difference is five quotes.toscrape.com tag pages (`/tag/<name>/page/1/`) that direct escalated to the browser and the gateway read over HTTP; both arms returned them as `success`. Why the HTTP verdict differed is not known; it was not investigated.
- Gateway bytes were not measured by Octocrawl; Webshare's dashboard has them. A Webshare GB is $3.50 on this plan; 74 pages are well under one.

## What it changes

- On these sites the exit is not what limits hosted Octocrawl: Cloud Run's Singapore address read 72 of 74, the gateway 72 of 74, the same pages. Statistics Canada, which this Mac's network cannot reach directly, answered Cloud Run directly on all 15.
- The gateway cost time on every site: p50 1.1 s → 3.6 s, p95 3.0 s → 9.7 s.
- **For H1:** the egress record does not support a proxy route for the crawl and batch sites. H1 starts with Cloud Run's direct egress, as ADR 0005 already requires of a hosted server. A site that blocks Cloud Run's address is not in this set: the blocking sites of batch L (BLS, Apple, GOV.UK statistics, Our World in Data) and the access task set were not run here, so this says nothing about them. A proxy route for hosted would also need a change to ADR 0005, which refuses proxies on a hosted engine.

## Script

```js
// H0 egress comparison (ROADMAP PH, stage H0): the same URLs on the parity crawl sites, read from Cloud Run
// directly (the hosted engine) and through the operator's residential gateway (W2L_EGRESS_PROXIES, a local-mode
// engine with an egress_sessions grant, as the hosted engine refuses proxies). One page at a time per arm and site;
// which arm reads a URL first alternates. Prints one JSON line per page and one summary line per arm and site.
import { createApiEngine } from '@w2l/api'
import { egressProxies, hostedNetworkPolicy, parseMapRequest, parseScrapeRequest } from '@w2l/contracts'

const PER_SITE = Number(process.env.H0_PER_SITE ?? 15)
const proxies = egressProxies(process.env.H0_PROXY)
if (proxies.length !== 1) throw new Error('H0_PROXY must name one proxy')
const common = { taskRoot: '/tmp/h0', networkPolicy: hostedNetworkPolicy(), defaultMaxPages: 1, allowRobotsOverride: false, sessionsFile: null, userChrome: null, workerCount: 2 }
const direct = createApiEngine({ ...common, hosted: true })
const gateway = createApiEngine({ ...common, taskRoot: '/tmp/h0g', hosted: false, egressProxies: proxies, egressEchoUrl: 'https://ipinfo.io/json',
  accessGrant: { tier: 'standard', capabilities: ['egress_sessions'], budget: { perRequestUsd: null, perRunUsd: null }, scope: { hosts: [] }, attestation: null, tariffs: {} } })

const ipinfo = await fetch('https://ipinfo.io/json').then((r) => r.json()).catch(() => null)
console.log(JSON.stringify({ h0: 'direct_exit', ip: ipinfo?.ip ?? null, country: ipinfo?.country ?? null, org: ipinfo?.org ?? null }))

// The hosts of the crawl and batch cases in research/parity/sites.md (L02, L04, L11, A13–A15, A26–A35).
const SITES = process.env.H0_SITES ? JSON.parse(process.env.H0_SITES) : [
  ['books', 'https://books.toscrape.com/'],
  ['quotes', 'https://quotes.toscrape.com/'],
  ['scrapethissite', 'https://www.scrapethissite.com/pages/'],
  ['docs.python', 'https://docs.python.org/3/'],
  ['data.gov.uk', 'https://www.data.gov.uk/search?q=energy'],
  ['statcan', 'https://www150.statcan.gc.ca/n1/en/type/data'],
  ['wikipedia', 'https://en.wikipedia.org/wiki/Web_crawler'],
]

const findKey = (o, key, d) => { if (!o || typeof o !== 'object' || d > 4) return null; if (key in o && o[key]) return o[key]; for (const v of Object.values(o)) { const f = findKey(v, key, d + 1); if (f) return f } return null }

async function read(engine, url) {
  const t0 = Date.now()
  try {
    const r = await engine.scrape(parseScrapeRequest({ url, formats: ['markdown'], timeout: 100000 }))
    const egress = findKey(r, 'egress', 0)
    return { ms: Date.now() - t0, status: r.status, reason: r.failureReason ?? r.blockReason ?? null, http: r.evidence?.httpStatus ?? r.metadata?.statusCode ?? null,
      lane: r.lane ?? null, chars: typeof r.markdown === 'string' ? r.markdown.length : 0, via: egress ? (egress.proxy ?? 'direct') : null, exit: egress?.exit?.country ?? null }
  } catch (e) { return { ms: Date.now() - t0, status: 'error', reason: String(e?.message ?? e).slice(0, 120), http: null, lane: null, chars: 0, exit: null } }
}

const summary = (pages) => {
  const ms = pages.map((p) => p.ms).sort((a, b) => a - b); const q = (f) => ms[Math.min(ms.length - 1, Math.floor(f * ms.length))]
  const tally = (k) => { const o = {}; for (const p of pages) o[p[k]] = (o[p[k]] ?? 0) + 1; return o }
  return { pages: pages.length, success: pages.filter((p) => p.status === 'success').length, byStatus: tally('status'), byReason: tally('reason'), byHttp: tally('http'), byLane: tally('lane'), p50ms: q(0.5), p95ms: q(0.95) }
}

const totals = { direct: [], gateway: [] }
for (const [site, start] of SITES) {
  let urls = []
  try {
    const m = await direct.map(parseMapRequest({ url: start, limit: 200, timeout: 60000 }))
    urls = [...new Set([start, ...(m.links ?? []).map((l) => l.url)])].slice(0, PER_SITE)
  } catch (e) { console.log(JSON.stringify({ h0: 'map_error', site, error: String(e?.message ?? e).slice(0, 120) })) }
  if (urls.length < PER_SITE) urls = [...new Set([...urls, start])]
  const arms = { direct: [], gateway: [] }
  for (const [i, url] of urls.entries()) {
    const order = i % 2 === 0 ? ['direct', 'gateway'] : ['gateway', 'direct']
    for (const arm of order) {
      const p = await read(arm === 'direct' ? direct : gateway, url)
      arms[arm].push(p); totals[arm].push(p)
      console.log(JSON.stringify({ h0: 'page', site, arm, url, ...p }))
    }
  }
  for (const arm of ['direct', 'gateway']) console.log(JSON.stringify({ h0: 'site', site, arm, ...summary(arms[arm]) }))
}
for (const arm of ['direct', 'gateway']) console.log(JSON.stringify({ h0: 'total', arm, ...summary(totals[arm]) }))
await direct.close?.(); await gateway.close?.()
process.exit(0)
```
