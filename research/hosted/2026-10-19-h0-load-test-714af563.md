# H0 load test: hosted engine on the hosted service's resources (2026-10-19)

ROADMAP PH stage H0, first measurement. The hosted engine ran in-process in a one-off Cloud Run Job, on the hosted service's image and resources, two pages at a time as one `octocrawl-api` instance at `--concurrency=2`. The job did not go through the gate, so it used no keyless, key, account or site allowance and touched no live traffic.

- **When:** 2026-10-19 06:11–06:19 UTC; execution `h0-loadtest-hkm22`, completed, 1 task succeeded.
- **Image:** `asia-southeast1-docker.pkg.dev/octopus-w2l-20260924-7r7/w2l-public-preview/hosted-api:714af563856738b8a4d150eb666df0de32b99f25`, the image of the live revision `octocrawl-api-lean-714af563` (`h25lean`).
- **Resources:** `--cpu=1 --memory=2Gi`, `asia-southeast1`, the service's values (`docs/hosted-api.md`).
- **Network:** direct from Cloud Run's own egress; no proxy.
- **Engine options:** as `createHostedApi` builds it: `hosted: true`, `hostedNetworkPolicy()`, `allowRobotsOverride: false`, `defaultMaxPages: 1`, `workerCount: 2`. robots.txt was obeyed for every URL and the per-host politeness interval applied.
- **Pages:** 774 unique URLs from `map` on 21 start pages: books.toscrape.com (home and catalogue pages 2–15), quotes.toscrape.com, and docs.python.org/3 (library, reference, howto, tutorial, c-api). Every third URL went to the browser set, the rest to the HTTP set. HTTP pages ran with `fastMode: true`; browser pages with `waitFor: 500`, which starts them in the browser.

## Cost per 1,000 pages (estimate)

At request-based billing an instance is billed while it serves, so two pages at a time bill the wall time above. List price for 1 vCPU and 2 GiB in asia-southeast1: $4.06e-05 per second (vCPU $0.0000336/s + 2 × $0.0000035/GiB-s, from the 2026-10-18 cost research in `docs/launch/2026-10-18-hosted-business-plan.md`; not the bill), before the free tier.

| Lane | Instance seconds per page | Compute per 1,000 pages | Requests ($0.40 per million) |
| --- | --- | --- | --- |
| HTTP | 0.331 | $0.0134 | $0.0004 |
| Browser | 1.308 | $0.0531 | $0.0004 |

What this leaves out, so it is a floor, not the cost:
- **Easy sites.** books.toscrape.com, quotes.toscrape.com and docs.python.org are light, static and do not block. Heavier pages, client-rendered pages and blocked pages take longer; the browser p50 of 2.75 s here is below the 9.0 s recorded for one hosted browser page (`research/hosted/2026-10-17-mcp-vs-firecrawl-9c971756.md`) and the 6.1 s local median (`research/access/runs/2026-10-12-pa4-92-main-48fd6e17.md`).
- **Not the service path.** No gate, Firestore commits, cold starts, idle instance time or Cloudflare; egress bytes are not counted.
- **The map calls** that collected the URLs (06:11:14–06:11:59) are not in either set.
- **List price, not billing.** The two-week billing record (ROADMAP PH item 3) still decides.

## What it changes

- The browser lane cost on easy pages is about a third of the cloud feature plan's assumption (8 s per page, two pages per vCPU, so about 4 instance seconds per page, against 1.31 measured); the plan's browser cost figures are upper bounds until heavier sites are measured.
- One instance at `--concurrency=2` used at most 60% of a vCPU and 19% of its memory. More pages per instance (a higher concurrency, or less memory) look possible; that is to be tested on heavier pages before the service changes.

## Script

```js
// H0 load test (ROADMAP PH, stage H0): the hosted engine in-process, on the hosted service's resources,
// two pages at a time as one Cloud Run instance at --concurrency=2. Prints one JSON summary line per phase.
import { readFileSync } from 'node:fs'
import { createApiEngine } from '@w2l/api'
import { hostedNetworkPolicy, parseMapRequest, parseScrapeRequest } from '@w2l/contracts'

const HTTP_PAGES = Number(process.env.H0_HTTP ?? 500)
const BROWSER_PAGES = Number(process.env.H0_BROWSER ?? 200)
const CONCURRENCY = 2

const cg = (file) => { try { return readFileSync(`/sys/fs/cgroup/${file}`, 'utf8') } catch { return null } }
const cpuUsec = () => { const s = cg('cpu.stat'); const m = s && s.match(/usage_usec (\d+)/); return m ? Number(m[1]) : null }
const memNow = () => { const s = cg('memory.current'); return s ? Number(s) : null }

const engine = createApiEngine({
  taskRoot: '/tmp/h0', networkPolicy: hostedNetworkPolicy(), hosted: true, defaultMaxPages: 1,
  allowRobotsOverride: false, sessionsFile: null, userChrome: null, workerCount: 2,
})

async function urlsFrom(start, limit) {
  const res = await engine.map(parseMapRequest({ url: start, limit, timeout: 60000 }))
  return (res.links ?? []).map((l) => l.url).filter((u) => u !== start).slice(0, limit)
}

async function run(label, urls, extra) {
  const cpu0 = cpuUsec(); let peak = memNow() ?? 0
  const sampler = setInterval(() => { const m = memNow(); if (m && m > peak) peak = m }, 250)
  const started = Date.now(); const pages = []; let next = 0
  async function worker() {
    while (next < urls.length) {
      const url = urls[next++]; const t0 = Date.now()
      try {
        const r = await engine.scrape(parseScrapeRequest({ url, formats: ['markdown'], timeout: 100000, ...extra }))
        pages.push({ ms: Date.now() - t0, status: r.status, lane: r.lane ?? r.evidenceRecord?.lane ?? null })
      } catch (e) { pages.push({ ms: Date.now() - t0, status: 'error', lane: null, error: String(e?.message ?? e).slice(0, 120) }) }
    }
  }
  await Promise.all(Array.from({ length: CONCURRENCY }, worker))
  clearInterval(sampler)
  const wallS = (Date.now() - started) / 1000; const cpu1 = cpuUsec()
  const ms = pages.map((p) => p.ms).sort((a, b) => a - b); const q = (f) => ms[Math.min(ms.length - 1, Math.floor(f * ms.length))]
  const count = (k, v) => pages.filter((p) => p[k] === v).length
  const byStatus = {}; for (const p of pages) byStatus[p.status] = (byStatus[p.status] ?? 0) + 1
  const byLane = {}; for (const p of pages) byLane[p.lane] = (byLane[p.lane] ?? 0) + 1
  console.log(JSON.stringify({ h0: label, pages: pages.length, wallS, cpuS: cpu0 != null && cpu1 != null ? (cpu1 - cpu0) / 1e6 : null,
    peakMemMiB: peak ? Math.round(peak / 1048576) : null, p50ms: q(0.5), p90ms: q(0.9), p95ms: q(0.95), p99ms: q(0.99), maxms: ms.at(-1),
    byStatus, byLane, errors: pages.filter((p) => p.error).slice(0, 5).map((p) => p.error), success: count('status', 'success') }))
}

const STARTS = [
  'https://books.toscrape.com/', 'https://quotes.toscrape.com/',
  ...Array.from({ length: 14 }, (_, i) => `https://books.toscrape.com/catalogue/page-${i + 2}.html`),
  'https://docs.python.org/3/library/', 'https://docs.python.org/3/reference/', 'https://docs.python.org/3/howto/',
  'https://docs.python.org/3/tutorial/', 'https://docs.python.org/3/c-api/',
]
const pools = []
for (const start of STARTS) pools.push(await urlsFrom(start, 300))
const all = [...new Set(pools.flat())]
console.log(JSON.stringify({ h0: 'pools', starts: STARTS.length, unique: all.length }))
const http = all.filter((_, i) => i % 3 !== 2).slice(0, HTTP_PAGES)
const browser = all.filter((_, i) => i % 3 === 2).slice(0, BROWSER_PAGES)
// fastMode keeps a page on the HTTP lane; waitFor above 0 starts it in the browser (the tool descriptions say so).
await run('http', http, { fastMode: true })
await run('browser', browser, { waitFor: 500 })
await engine.close?.()
process.exit(0)
```
