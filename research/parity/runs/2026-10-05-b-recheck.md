The [group B run](2026-10-04-b-acceptance.md) found three faults, fixed since by #197, #199 and #201. This run repeats the steps that showed them, on main with those fixes.

## Setup

- **Source commit:** `9f561e8` (main after PRs #198, #199 and #201). `w2l` stands for `npm run -s w2l --`.
- **W2L's own fetches:** **proxied** through the shell's `HTTPS_PROXY` (127.0.0.1:7890).
- **The person's Chrome:** Howard's Chrome 153.0.8010.53, default profile, remote debugging on. It used its own network settings, which were not recorded. Howard clicked Allow at each connection and signed in and out of Airbnb himself.
- **Saved logins:** a scratch `W2L_SESSIONS_FILE` (`.w2l/b-recheck/sessions.json`), deleted after the run.
- **What this record holds:** statuses, counts, event names, titles and the CLI's notices only.
- **Where the figures come from:** each scrape's JSON and stderr were saved under `.w2l/b-recheck/` (git-ignored), with each read's `compliance.requestedAt`. These were read from the commands' output during the session and not kept as files:
  - the import's answer;
  - the exit codes.
